# DIY / DIY-AI 共用改动同步核对

核对日期：2026-09-22。范围为用户 fork 的 `diy` 与 `diy-ai`，
不包括官方仓库、PR 合并、线上部署或数据库迁移。

## 同步约定

共用功能的修改应在两个分支分别检查、实现和验收；一次只提交到其中一个分支，
不能视为双分支完成。比较最终行为、配置、语言字段和场景接线，不仅比较提交哈希。
卡牌规则不同的地方按各分支实际实现修正文案，不能复制整份语言文件或覆盖整分支。
提交、推送和部署分别报告；本轮只创建本地提交。

- AI 的普通/闪卡资源包能力检查、部分专用卡面、默认语言偏好隔离、运行时版本、
  端点、部署服务、奖励队列及旧客户端兼容存储结构，不以文件相同为目的回迁。
  两边奖励/闪卡的产品功能一致，不代表存储和调度实现完全相同。
